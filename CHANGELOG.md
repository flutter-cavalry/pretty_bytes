## 7.0.0

- Breaking: `prettyBytes` now takes an `int` instead of a `double` (file sizes are integers).
- Fix: `binary: false` no longer selects the binary (1024) base.
- Fix: min/max fraction digits no longer crash and apply without a locale.
- Fix: boundary values no longer produce `1000 TB` instead of `1 PB`.
- Fix: invalid (non-finite) inputs are no longer accepted via `double`.
